🧩 마음해결사
"고쳐드립니다, 당신의 기억" > 현대인의 엇갈린 감정을 조율하는 내러티브 기반 협력 퍼즐 게임

📖 프로젝트 개요
[마음해결사]는 갈등의 끝에 선 사람들의 추억을 복원하고, 서로의 진심을 연결하는 2인 협력 퍼즐 게임입니다.
플레이어는 '마음해결사' 듀오가 되어, 싸움의 파편 뒤에 숨겨진 진심을 찾아가는 감성적인 여정을 떠납니다.

장르: 내러티브 협력 퍼즐 
핵심 키워드: 비언어적 소통, 감정의 공유, 협력, 복원

✨ 핵심 기획 포인트
1. 비언어적 소통 시스템
채팅 없는 교감 : 언어적 소통(채팅)을 배제하고 이모지와 간단한 매크로만을 사용하여, 상대방의 움직임과 감정 표현에 더 집중하도록 설계했습니다.

2. 완벽한 앙상블 
보폭 맞추기 : 한 명의 뛰어난 플레이가 아닌, 서로의 위치를 확인하고 길을 열어주어야만 전진할 수 있는 레벨 디자인을 구현했습니다.
공동 조작 시스템: 두 명의 입력이 동시에 일치해야 작동하는 퍼즐 기믹을 통해 '협력'의 본질적인 재미를 담았습니다.

3. 멀티 엔딩 & 감정 보고서 
속도와 진심: 목적지에 도달하는 속도와 방식에 따라 '앞서버린 감정' 혹은 '서로에게 닿은 진심' 등의 멀티 엔딩을 제공합니다.
비밀 일기와 편지: 클리어 후 제공되는 에필로그를 통해 사건 주인공들의 숨겨진 속마음을 수집품 형태로 획득하며 서사의 완결성을 높였습니다.


👥 Team: 마음을 잇는 사람들
Scenario Designer (김남훈) : 갈등과 화해의 서사 집필 및 텍스트 가이드 작성
System & Level Designer (변대한) : 퍼즐 레벨 설계 및 커뮤니케이션 시스템 기획
Main Developer (송준엽) : 실시간 동기화 구현 및 전체 게임플레이 개발

💡 기획 의도 한마디
"말로는 다 전하지 못한 진심이 퍼즐을 푸는 과정을 통해 상대에게 닿기를 바라는 마음으로 설계했습니다. 단순한 클리어가 목적이 아닌, 서로의 마음의 거리를 좁혀가는 경험을 선물하고 싶었습니다."
